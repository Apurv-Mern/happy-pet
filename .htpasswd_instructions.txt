# .htpasswd file instructions

1. SSH into your server or use an online generator:
   https://hostingcanada.org/htpasswd-generator/

2. Generate a line for your username and password (e.g., admin / happy123)
   Example output:
   admin:$apr1$xyz$encryptedpasswordhash

3. Save this line in a file named .htpasswd

4. Upload .htpasswd to a secure location OUTSIDE your public_html/web root, e.g.:
   /home/yourusername/.htpasswd

5. Update the AuthUserFile path in .htaccess to match the actual location.

6. Set permissions:
   chmod 644 .htpasswd

7. Test your site: You should see a login popup.
